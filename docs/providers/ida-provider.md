# Retired IDA provider

REA uses Ghidra for deep native analysis. To update older IDA provider
selections and agent registrations, follow the
[migration instructions](../getting-started/installation.md#migrate-an-older-native-provider-configuration).

Previously retained Evidence keeps its original provider identity. The
[historical IDA guide](https://github.com/morluto/rea/blob/0909d89c966c30955fd0906b622ff25f3700789f/docs/providers/ida-provider.md)
describes the behavior and verification of earlier versions.
